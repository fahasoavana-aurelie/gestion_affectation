# Gestion d'affectation

## Présentation

**Gestion d'affectation** est une application web développée en PHP et MySQL dans le cadre d'un projet académique. Elle a pour objectif de faciliter la gestion des employés et des affectations au sein d'une organisation.

## Technologies utilisées

- **PHP** : logique côté serveur
- **MySQL** : gestion de la base de données
- **HTML / CSS** : interface web, si utilisés dans le projet

## Fonctionnalités

L'application comprend plusieurs modules :

- Gestion des employés
- Gestion des affectations et des lieux
- Authentification et déconnexion
- Consultation de l'historique
- Génération ou impression de documents liés aux affectations, selon les fonctionnalités disponibles

## Structure du projet

- `index.php` : page d'accueil
- `login.php` : connexion
- `logout.php` : déconnexion
- `db.php` : connexion à la base de données
- `employes.php` : gestion des employés
- `affectations.php` : gestion des affectations
- `lieu.php` : gestion des lieux
- `historique.php` : historique
- `README.md` : documentation du projet

## Installation

1. Installer un environnement PHP et MySQL, par exemple XAMPP.
2. Cloner ou télécharger ce dépôt GitHub.
3. Placer le dossier du projet dans le répertoire web local de XAMPP (`htdocs`).
4. Créer la base de données MySQL nécessaire.
5. Importer le fichier SQL de la base de données, s'il est fourni dans le projet.
6. Configurer la connexion à la base de données dans `db.php`.
7. Démarrer Apache et MySQL, puis ouvrir le projet dans le navigateur.

> Les étapes exactes dépendent de la structure réelle de la base de données et de la configuration du projet.

## Objectif du projet

Ce projet m'a permis de mettre en pratique mes connaissances en développement web avec PHP et MySQL, notamment dans la gestion des données et la création d'une application web.
